# Quantara — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Head of Analytics

- As analytics lead, I want cases scored on readiness before funding, so that we stop starting ML without data or a hypothesis.
- As analytics lead, I want failed cases retained, so that our ROI culture is not survivor-biased.

### Finance controller

- As finance, I want benefit families and cost components standardised, so that I can compare a personalisation bet to a maintenance bet.
- As finance, I want estimate vs realized ROI side by side after year one, so that we recalibrate the 2–5× folklore.

### ML product owner

- As a product owner, I want the define-stage checklist forced (problem, hypothesis, measure, benchmark, data), so that execution starts clean.
- As a product owner, I want vendor cost and implementation share visible, so that I am not surprised when implementation hits 40%.

### Vendor manager

- As procurement, I want customisation and duration recorded, so that bids are comparable.
- As procurement, I want continue-to-invest decisions logged, so that renewals are not automatic.

### Executive sponsor

- As sponsor, I want capital vs efficiency vs revenue benefits explicit, so that I know which P&L line moves.
- As sponsor, I want transformation readiness scored, so that model success is not mistaken for business success.
